# Визуализатор зависимостей пакетов
Вариант №8. Язык программирования Java.

## Этап 1

Программа читает настройки из JSON-файла, проверяет их и выводит
в формате `ключ=значение`. При неправильных данных сообщает об ошибке.
Поиск зависимостей пока не реализован.

## Файлы проекта

- `src/Main.java` — запуск программы и чтение файла.
- `src/Config.java` — хранение и вывод настроек.
- `src/ConfigLoader.java` — проверка параметров.
- `src/FlatJson.java` — разбор JSON.
- `config.json` — настройки программы.
- `examples/test-repository.json` — тестовый репозиторий.
- `tests/ConfigLoaderTest.java` — проверки настроек.
- `run.sh` — сборка и запуск программы.
